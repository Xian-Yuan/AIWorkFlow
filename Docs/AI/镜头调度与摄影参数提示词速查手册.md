## 5. 镜头行为序列 (Lens Behavior Sequence)

> 来源: Higgsfield vocab.md -- 比单纯写景深状态更有效的方法

**核心原则**: 把焦点/景深事件描述为**叙事序列**(trigger -> shift -> state -> return)，而不是单一静态状态。

**示例**:
```
Focus opens on the knight. As the raven crosses the lens plane,
focus shifts onto it -- the knight softens into warm bokeh.
The raven flies past. Focus breathes back to the knight.
This cycle repeats organically 2-3 times.
```

**关键词汇**:
- **shallow depth of field** -- 窄锐平面，前后虚化
- **focus-breathing** -- 有机焦点飘移
- **rack focus** -- 刻意焦点转移
- **bokeh silhouette** -- 虚化主体变成柔和暖色形状
- **lens plane crossing** -- 前景元素穿越焦平面的瞬间
- **anamorphic lens rendering** -- 椭圆散景，水平耀斑，宽银幕感

## 6. 四层运动层级 (Motion Hierarchy)

> 来源: Higgsfield vocab.md -- 同时出现的多层运动必须分别命名

| 层 | 内容 | 示例(骑士拔剑) |
|----|------|---------------|
| 1. 主体运动 | 角色做什么 | 骑士转身拔剑 |
| 2. 内部运动 | 主体内的微运动 | 头发飘动、呼吸起伏、披风摆动 |
| 3. 摄影机运动 | 摄影机做什么 | 缓慢推近 10% |
| 4. 环境运动 | 世界在做什么 | 雨滴、远处旗帜飘动、火把摇曳 |

**原则**: 每层分别描述，防止多层运动叠加导致生成失败

## 7. 摄影机契约 (Camera Contract)

> 来源: Higgsfield vocab.md -- 在描述主体/动作之前，先声明摄影机行为规则

**三种常见契约**:

| 契约 | 英文提示词 | 用途 |
|------|-----------|------|
| 静态锁定 | Static locked-off camera. Zero movement. No pan, no zoom, no dolly, no shake. | 氛围/产品展示/神圣场景 |
| 缓慢推入 | Slow push-in only -- 10% scale change over the full duration. | 情感递进、顿悟、单人场景 |
| 手持漂移 | Single handheld drift, slight organic sway, no cuts. | 纪实/亲密/低质感 |

**负面提示词必须镜像**: 
- 正面: `Static locked-off camera.` → 负面: `camera movement, pan, zoom, dolly, shake`

## 8. 构图与空间分区 (Composition)

### 8.1 构图规则

| 规则 | 英文提示词 | 效果 |
|------|-----------|------|
| 三分法 | rule of thirds, subject at third intersection | 经典平衡 |
| 中心构图 | centered, symmetrical framing | 正式/神圣/权力 |
| 引导线 | leading lines, perspective vanishing point | 纵深/方向感 |
| 框架构图 | framed by doorway/archway/window | 层次/窥视 |
| 负空间 | negative space, deliberate emptiness | 孤独/强调/极简 |
| 前景遮挡 | foreground element, partially obscured | 纵深/窥视/神秘 |

### 8.2 空间分区提示词

| 区域 | 英文提示词 | 用途 |
|------|-----------|------|
| 左三分之一 | left third | 放置主体 |
| 右三分之二 | right two-thirds | 动作区域 |
| 前景平面 | foreground plane | 粒子/遮挡 |
| 中景 | midground | 主要动作 |
| 背景 | background, unlit void | 氛围/远景 |
| 上半部 | upper half | 天空/命运 |
| 下半部 | lower half | 地面/泥土 |

### 8.3 坐标标注

```
Character A stands in the right third,
x-position 70%, y-position 50%, frame occupancy 25%
```

### 8.4 越轴规则

- **180度规则**: 摄影机保持在两个主体之间假想线的一侧，跳轴会让观众迷失方向
- **越轴规则**: 角色在镜头中的左右位置不可随意交换 -- "角色A在左，角色B在右，不越中线"
- **切点手势锚定**: 两个单独生成的片段要剪切干净，让上一个场景的最后一帧和下一个场景的第一帧包含**相同重复的手势**(如转头/推门/手按剑柄)

## 15. 9:16竖屏构图专用规则 (Vertical Composition for Douyin)

> 来源: awesome-ai-visual-realism-prompts 03-composition.md 竖屏适配
> 原理: 竖屏不是横屏裁掉两边，而是一种全新的空间逻辑——垂直纵深取代水平展开

### 15.1 竖屏安全区

| 区域 | 位置 | 用途 | 百分比 |
|------|------|------|--------|
| 头部安全区 | 画面上 15% | 顶部UI/标题遮挡区 | 避免放关键信息 |
| 视觉焦点区 | 上 25%-65% | 人脸/表情/手部/核心动作 | 主要叙事区 |
| 动作展开区 | 中 40%-80% | 身体/武器的垂直运动 | 动作戏核心 |
| 底部安全区 | 下 10% | 字幕/互动按钮遮挡区 | 避免放关键信息 |
| 左右留白 | 两侧各 10% | 竖屏天然窄边 | 避免主体贴边 |

### 15.2 竖屏构图六式

| 构图 | 英文提示词 | 逻辑 | 西幻场景 |
|------|-----------|------|----------|
| 垂直纵深法 | vertical depth, tall corridor, looking up, vanishing point above | 利用竖屏天然纵深，从下到上建立空间 | 大教堂穹顶仰视、城堡高塔内部 |
| 上下分割法 | upper-lower split, sky above/ground below, horizontal divide at 40% | 上半环境/下半角色，或反之 | 骑士跪地(下)/天空(上) |
| 中心纵列法 | central vertical axis, subject centered, vertical symmetry | 角色沿中轴线从上到下展开 | 骑士全身肖像(头盔到靴子) |
| 框中框法 | framed by archway, window frame composition, vertical frame-within-frame | 利用拱门/窗框/门框竖向框住主体 | 城门内骑士剪影、拱廊下对话 |
| 负空间留白 | negative space above/below, isolated figure, vast vertical emptiness | 大面积留白制造孤独/崇高 | 高塔上孤身一人，上方空旷天空 |
| 前景遮挡纵深 | foreground element at bottom, depth layers vertical, parallax vertical | 底部前景遮挡+中景+远景纵深 | 低角度拍摄，前景石块/中景骑士/远景城堡 |

### 15.3 竖屏运镜适配

| 横屏运镜 | 竖屏适配 | 注意事项 |
|----------|---------|----------|
| 横移(dolly left/right) | 改为升降(crane up/down) | 竖屏水平空间有限，用垂直运动替代 |
| 宽幅全景(landscape wide) | 改为垂直全景(vertical reveal) | 从地面摇到天空，展示高度而非宽度 |
| 双人同框(horizontal two-shot) | 改为上下双人(vertical two-shot) | 前景人物+背景人物垂直排列 |
| 马路追车水平运动 | 改为楼梯/塔楼垂直追逐 | 利用竖屏天然高度做垂直运动 |
| 环绕(360 orbit) | 保留但裁切中心区域 | 竖屏环绕仍可用，但注意两侧安全区 |

## 16. 物理真实感反AI糊片清单 (Physical Realism Anti-Slop Checklist)

> 来源: awesome-ai-visual-realism-prompts 01-physical-realism.md
> 原理: AI最常翻车的地方不是大结构，而是物理细节。以下8层是观众潜意识感知"真/假"的关键

### 16.1 八层物理真实感

| 层 | 物理属性 | 英文提示词 | AI常见翻车 | 中世纪西幻重点 |
|---|---------|-----------|-----------|---------------|
| 1. 皮肤次表面散射 | 皮肤透光(Skin SSS) | subsurface scattering on skin, light penetrating epidermis, warm translucency at ears/fingers | 皮肤像塑料/蜡像 | 战场血污+汗渍下皮肤仍透光；精灵皮肤SSS更强 |
| 2. 液体菲涅尔+焦散 | 液体反射/折射 | Fresnel reflection on liquid surface, caustic light patterns underneath, realistic water refraction | 水像固体/无折射 | 药水/血泊/溪流必须有Fresnel和焦散 |
| 3. 布料各向异性编织 | 布料纹理方向性 | nisotropic cloth weave, thread-level detail, directional fabric reflection | 布料像光滑塑料/无编织感 | 天鹅绒/粗麻/铠甲内衬的编织方向不同 |
| 4. 接触物理 | 物体接触面 | contact physics, weight distribution, surface compression at contact points | 物体漂浮/无重量感 | 剑放在桌上必须有压痕/阴影贴合；手握杯必须有接触变形 |
| 5. 解剖结构 | 骨骼/肌肉 | natomically correct, muscle insertion points, skeletal landmarks visible under skin | 手指数错/关节位置错误 | 铠甲下的身体轮廓必须符合解剖；握剑的手指位置正确 |
| 6. 大气透视 | 远处物体散射 | tmospheric perspective, aerial haze, distant objects desaturated and blue-shifted | 远处物体与近处一样清晰 | 城堡远景必须有大气散射/偏蓝；森林深处必须雾化 |
| 7. 光线弹射 | 间接照明/色溢 | ounce light, color spill from nearby surfaces, indirect illumination | 暗部全黑/无反射光 | 火把照亮的石墙必须向附近物体弹射暖光；铠甲必须反射环境色 |
| 8. 质感微细节 | 表面微纹理 | micro-surface detail, pores, scratches, patina, weathering, wear patterns | 所有表面光滑无瑕 | 铠甲必须有划痕/锈蚀；旧书必须有泛黄/虫蛀；石墙必须有风化 |

### 16.2 每镜头必检清单

在提交任何提示词前，逐项检查:

- [ ] 皮肤: 是否有SSS提示词？(塑料脸 = 直接废片)
- [ ] 液体: 场景有水/血/药水吗？是否有Fresnel？
- [ ] 布料: 角色服装是否有编织质感？(塑料布 = 假)
- [ ] 接触: 手握/放置物体是否有接触物理？(漂浮物 = 假)
- [ ] 解剖: 手部特写是否指定正确指节数量？
- [ ] 大气: 远景是否有大气透视？
- [ ] 光弹: 暗部是否有间接光/色溢？
- [ ] 微纹理: 铠甲/石墙/木器是否有磨损/划痕？

### 17.2 模式选择决策树

`
场景需要角色说话吗？
├─ 是 → 对话是日常还是对峙？
│       ├─ 日常 → Narrative模式
│       └─ 对峙 → Studio模式(锁定对峙特写)
└─ 否 → 场景有动作吗？
        ├─ 是 → 打斗还是仪式？
        │       ├─ 打斗 → Action模式
        │       └─ 仪式 → Performance模式
        └─ 否 → Atmospheric模式
`

### 17.3 模式间转换

| 转换 | 触发条件 | 转换手法 | 示例 |
|------|---------|---------|------|
| Narrative→Action | 冲突爆发 | 急推变焦(crash zoom)+手持 | 谈判破裂瞬间 |
| Action→Studio | 动作高潮定格 | 升格慢动作+锁定 | 剑交汇瞬间 |
| Studio→Atmospheric | 情绪沉淀 | 缓慢拉远+色调渐变 | 顿悟后沉思 |
| Atmospheric→Performance | 神圣时刻 | 逆光涌入+环绕启动 | 魔法觉醒 |
| Performance→Narrative | 仪式结束 | 运动收敛+色调正常化 | 宣誓完成回归日常 |

## 19. 情绪可见行为编码 (Emotion as Visible Behavior)

> 来源: Higgsfield vocab.md "Emotion as Visible Behavior"
> 原理: 情绪不是脸上一个表情，而是全身8个通道同时发生的物理变化。写出8通道，AI生成的角色才"活着"

### 19.1 八通道情绪行为

| 通道 | 英文提示词 | 含义 | 西幻示例(悲壮态A-07) |
|------|-----------|------|---------------------|
| 1. 呼吸 | breathing pattern: [shallow/deep/ragged/holding] | 呼吸节奏 | ragged breathing, chest heaving irregularly |
| 2. 眼部行为 | eye behavior: [darting/fixed/glistening/lid-heavy] | 眼球运动 | eyes glistening, fixed on distant horizon |
| 3. 下颌张力 | jaw tension: [clenched/relaxed/grinding/slack] | 下颌状态 | jaw clenched, muscles visible under skin |
| 4. 失焦 | loss of focus: [present/distant/unfocused/staring-through] | 注意力去向 | staring through the scene, thousand-yard stare |
| 5. 扫描模式 | scanning pattern: [sweeping/locked/avoidant/flinching] | 视线搜索 | eyes locked forward, not scanning |
| 6. 延迟恢复 | delayed recovery: [instant/slow/frozen/never-recovered] | 反应延迟 | delayed blink, slow to respond to sound |
| 7. 控制尝试 | control attempt: [suppressing/masking/steadying/failing] | 压抑努力 | hand steadying on sword hilt, suppressing tremor |
| 8. 情绪残留 | emotional residue: [afterglow/aftertaste/scar/echo] | 情绪余韵 | residual redness around eyes, shoulders still tight |

### 19.2 三种情绪的8通道完整编码

**A-07 悲壮态**(骑士赴死前):
- breathing: deep and slow, deliberate
- eye behavior: glistening, fixed ahead
- jaw tension: clenched, grinding
- loss of focus: distant, seeing something far away
- scanning pattern: locked forward
- delayed recovery: slow blink, delayed response
- control attempt: steadying hand on sword, suppressing tremor
- emotional residue: residual wetness in eyes, shoulders squared against weight

**A-10 狂热态**(禁忌魔法发动):
- breathing: rapid, shallow, excited
- eye behavior: wide, pupils dilated, darting to magical energy
- jaw tension: slack, mouth slightly open
- loss of focus: hyper-focused on magic, oblivious to surroundings
- scanning pattern: sweeping, tracking energy flows
- delayed recovery: instant, over-responsive
- control attempt: no control, surrendered to the flow
- emotional residue: afterglow of magical light on face, pupils slow to contract

**A-14 隐忍态**(被屈辱但不能发作):
- breathing: held, then slow measured exhale
- eye behavior: half-closed, not meeting gaze
- jaw tension: tight, muscles visibly clenched
- loss of focus: present but deliberately avoiding
- scanning pattern: avoidant, not looking at the source of humiliation
- delayed recovery: frozen, processing
- control attempt: intensely suppressing, fist hidden behind back
- emotional residue: jaw still tight, a single muscle twitch near the eye



## 20. 结构化提示词输出格式 (Structured Prompt Output Format)

> 来源: AI-Cinematic-Prompt-Director
> 原理: 提示词不是一句话，而是一个从意图分析到逐镜头矩阵的结构化文档

### 20.1 四步输出流程

**Step 1: Intent Analysis**(意图分析)
- 这段场景的核心情绪是什么？
- 观众应该感受到什么？
- 关键转折点在哪？

**Step 2: Director Vision**(导演视觉)
- 导演风格锚定(查18节查表)
- DP灯光签名锚定(查13节)
- 构图签名锚定(查14节)
- 整体调色方向(查11节)

**Step 3: Shot-by-Shot Prompt Matrix**(逐镜头提示词矩阵)

| 镜号 | 时长 | 景别 | 运镜 | 灯光 | VFX/质感 | 主体/动作 | 对话 | 环境 | 原始AI提示词 |
|------|------|------|------|------|----------|----------|------|------|------------|

**Step 4: Style Anchor**(风格锚定)
- 胶片模拟(查12节)
- 物理真实感层(查16节)
- 负面提示词

### 20.2 集成提示词解剖公式

一个完整的AI视频提示词由6个模块组成:

`python
Prompt = (
    Subject_and_Action    # 主体+动作(谁+做什么)
  + Physical_Realism      # 物理真实感(8层清单)
  + Lighting_DP_Anchored  # 灯光(DP签名锚定)
  + Composition_Director  # 构图(导演签名锚定)
  + Camera_Lens_Motion    # 摄影(运镜+焦距+景深)
  + Style_Anchor          # 风格锚定(调色+胶片+负面词)
)
``n
**完整示例(骑士赴死):**

`python
# Subject + Action
"A weathered knight in blackened plate armor kneels before the cathedral door,
 sword planted in stone beside him."

# Physical Realism
"Subsurface scattering on rain-wet skin. Anisotropic weave on torn cloak.
 Contact physics: knees pressed into wet stone, weight distributed.
 Atmospheric haze on distant towers. Bounce light from torch brackets."

# Lighting (Deakins-style)
"Single motivated key from cathedral doorway, negative fill on shadow side,
 no top light, naturalistic, Deakins-style."

# Composition (Kubrick-style)
"Perfect symmetry, one-point perspective down the nave,
 centered subject, wide angle depth, Kubrick-style."

# Camera + Lens
"Slow dolly in, 35mm wide, moderate DOF f/4, vertical 9:16 frame,
 subject in lower 40% (kneeling), upper 60% cathedral interior."

# Style Anchor
"Cinematic dark fantasy, Kodak Vision3 500T, cold blue shadows,
 crushed blacks, anamorphic rendering, 4K, masterpiece.
 Negative: bright, cartoon, anime, blurry, deformed, watermark."
``n
### 20.3 快速组装: 60秒提示词

当时间有限时，用以下最小组装:

`python
MinPrompt = f
  "[Subject+Action], "
  "[DP lighting style], "
  "[Director composition style], "
  "[Lens+DOF+Motion], "
  "[Color grade], "
  "[Film stock], "
  "9:16 vertical, cinematic"
`python

**示例:**

"A knight kneels in rain, Deakins single key light, Kubrick centered symmetry,
 35mm slow dolly in f/4, cold blue crushed blacks, Vision3 500T,
 9:16 vertical, cinematic dark fantasy"

## 21. 构图心理学与视觉流动 (Composition Psychology)

> 来源: director-style-kb/cinematography-deep-dive.md 第1节
> 原理: 构图不只是"把人放哪"，而是利用人脑的视觉组织机制(格式塔)引导观众感受

### 21.1 格式塔五原则

| 原则 | 构图应用 | 情绪 | AI提示词 |
|------|---------|------|---------|
| 接近性 | 角色靠近=亲密;远离=疏离 | 亲密/疏离 | intimate proximity / social distance, far apart |
| 相似性 | 相同颜色=同阵营 | 归属/区分 | matching color, same faction / distinct color, outsider |
| 连续性 | 引导线指向重点 | 方向/必然 | leading lines to subject / roken line, visual dissonance |
| 闭合性 | 框架切掉部分=观众脑补 | 参与感/悬念 | partially framed, implied complete, frame-within-frame |
| 图底关系 | 清晰图底=安全感;模糊=不安 | 安定/焦虑 | clear figure-ground, subject isolated / mbiguous figure-ground, blending |

### 21.2 视觉重量引力场

| 重量元素 | 重量 | 效果 | 提示词 |
|---------|------|------|--------|
| 暗色区域 | 重(下坠) | 底部暗=压迫 | heavy bottom, dark ground, weight below |
| 亮色区域 | 轻(上升) | 上方亮=升华 | light above, ascending weight, spiritual lift |
| 暖色 | 重(前进) | 暖色中心=紧迫 | warm accent forward, attention magnet |
| 冷色 | 轻(后退) | 冷色边缘=疏远 | cold edges, receding distance |
| 人物面部 | 极重 | 面部在哪=焦点 | ace as visual magnet, attention anchor |

### 21.3 八种视觉流动

| 流动 | 情绪 | 提示词 | 西幻场景 |
|------|------|--------|---------|
| Z形 | 日常叙事 | Z-pattern flow, natural reading | 教堂内部 |
| 对角线 | 动态冲突 | diagonal flow, dynamic tension | 骑士冲入 |

## 22. 景别亲密梯度 (Shot Size as Intimacy)

> 来源: director-style-kb/cinematography-deep-dive.md 第2节
> 原理: 景别=观众与角色的心理距离。越近越亲密，越远越疏离。

### 22.1 十级景别与心理距离

| 级 | 景别 | 心理距离 | 情绪 | AI提示词 |
|----|------|---------|------|---------|
| 1 | EWS | 无限远 | 渺小/宿命 | extreme wide, tiny figure in vast landscape, EWS |
| 2 | WS | 远 | 客观/建立 | wide shot, establishing, WS |
| 3 | FS | 中远 | 动作明确 | ull shot, full body, FS |
| 4 | MFS/Cowboy | 中 | 准备行动 | cowboy shot, mid-thigh up, MFS |
| 5 | MS | 中近 | 社交/对话 | medium shot, waist up, MS |
| 6 | MCU | 近 | 亲密对话 | medium close-up, chest up, MCU |
| 7 | CU | 很近 | 情感聚焦 | close-up, face filling frame, CU |
| 8 | ECU | 极近 | 强迫观看 | extreme close-up, single detail, ECU |
| 9 | Macro | 显微 | 不可见之可见 | macro shot, microscopic detail |
| 10 | Insert | 无(物件) | 信息/线索 | insert shot, object detail |

## 27. 镜头心理学深潜 (Lens Psychology Deep Dive)

> 来源: 摄影学理论 + DP访谈 + 导演创作手记整合
> 原理: 焦距不只是"拍多宽"，而是选择观众**以什么心理姿态**观看场景。每一段焦距都自带一种世界观。

## 28. 反应镜头与对切语法 (Shot/Reverse Shot & Reaction Grammar)

> 来源: 经典好莱坞对话语法 + 当代导演对切创新 + 短视频节奏适配
> 原理: 对话场景的情绪不在"说话的人"，而在"听的人"的反应。反应镜头才是情绪的真正载体。

### 28.1 对切六式

| 式 | 镜头构成 | 情绪 | 提示词 | 西幻示例 |
|----|---------|------|--------|---------|
| 标准对切 | OTS↔OTS, 180度线内 | 中性/建立关系 | `standard OTS shot/reverse shot, 180-degree rule, neutral dialogue` | 骑士与领主对话 |
| 渐近对切 | OTS→MCU→CU→ECU | 压力/真相逼近 | `progressive close-in shot/reverse shot, tightening OTS to ECU, pressure building` | 审讯: 每次切回更近 |
| 不对等对切 | A宽B窄/ A远B近 | 权力不对等 | `asymmetric shot/reverse shot, A in WS B in CU, power imbalance` | 国王远景↔骑士特写 |
| 越轴对切 | 切换时跳过180度线 | 关系翻转/震惊 | `axis-crossing shot/reverse shot, screen direction reversal, power shift` | 背叛瞬间: 位置突然"错"了 |
| 反应优先 | 说话人声音+听者特写 | 听者情绪>说者内容 | `reaction-first, speaker audio + listener close-up, reaction drives emotion` | 宣判时镜头在被告脸上 |
| 单人切 | 只有A，B在画外/只听声音 | 孤立/缺席/单方面 | `one-sided shot, only A visible, B off-screen or voice only, isolation` | 被放逐者独对黑暗 |

### 28.2 反应镜头四原则

**原则1: 反应大于动作**
- 观众的情绪跟着反应者走，不是跟着行动者走
- 提示词: `reaction shot priority, cut to listener's face on key dialogue`

**原则2: 延迟反应=内心复杂**
- 反应越延迟，说明内心越复杂(震惊→消化→回应)
- 提示词: `delayed reaction, 2-beat pause before response, processing shock`

**原则3: 微反应>大反应**
- 眼睛微微一颤比嚎啕大哭更有力(可控vs失控)
- 提示词: `micro-reaction, subtle eye shift, controlled emotion, single muscle twitch`

**原则4: 无反应=最强反应**
- 当所有人都期待反应时，没有反应最震撼(麻木/超脱/已死)
- 提示词: `no reaction, blank stare, emotional absence, beyond feeling, numb`

### 28.3 情绪传递链——从说话到反应到观众

| 传递链 | 含义 | 提示词模板 | 西幻示例 |
|--------|------|-----------|---------|
| 说话→消化→回应 | 正常信息处理 | `speaker says [X], listener processes 2-beat, then responds` | 领主传达命令，骑士消化后领命 |
| 说话→震惊→沉默 | 无法回应 | `speaker drops truth, listener stunned into silence, lips parted` | "你的父亲...已经死了" |
| 说话→压抑→爆发 | 强忍后崩溃 | `speaker accuses, listener suppresses then breaks, clenched jaw to trembling` | "你才是那个叛徒！" |
| 说话→微笑→阴冷 | 伪善/阴谋 | `speaker reveals, listener smiles slowly, cold eyes, false warmth` | "哦，是吗...那太好了" |
| 说话→无表情→转身离开 | 彻底放弃 | `speaker begs, listener shows nothing, turns and walks away` | "我不再求你了" |
| 沉默→沉默→沉默 | 共同的悲痛 | `both silent, shared grief, no words needed, eyes meet briefly` | 两人站在墓前无言 |

### 28.4 沉默即叙事——无声镜头的五种用法

| 沉默类型 | 持续 | 情绪 | 提示词 | 西幻场景 |
|---------|------|------|--------|---------|
| 暴风雨前的静 | 2-4秒 | 紧张/等待/不祥 | `stillness before storm, charged silence, anticipation` | 战前最后的对视 |
| 震惊的空白 | 1-2秒 | 大脑短路 | `stunned silence, frozen moment, blank processing` | 真相揭露后的停顿 |
| 悲伤的虚空 | 3-5秒 | 失去/空虚 | `grief silence, hollow void, nothing left to say` | 死亡确认后的长停 |
| 权力的压迫 | 4-6秒 | 窒息/等待裁决 | `power silence, deliberating pause, weight of judgment` | 国王沉默不语，所有人等待 |
| 顿悟的清明 | 2-3秒 | 透明/理解 | `clarity silence, understanding dawning, world rearranged` | 终于明白真相的瞬间 |

### 28.5 竖屏对切适配(抖音专用)

| 横屏对切 | 竖屏适配 | 注意事项 |
|---------|---------|---------|
| 左右OTS | 上下分割/前后景 | 竖屏水平空间不足，用上下分层 |
| 双人同框 | 一人在上/一人在下 | 利用竖屏高度做双人垂直排列 |
| OTS宽构图 | 极简背景+单人脸 | 竖屏对话=放大情绪，减掉环境 |
| 全身行走对话 | 上半身对话+步行动作 | 只拍到腰部，竖屏裁掉腿 |

## 30. 构图即情绪 (Composition as Emotion)

> 来源: cinematography-deep-dive.md + director-visual-narrative.md + 经典电影构图分析
> 原理: 构图不是"安排元素"，是"安排情绪"。每种构图模式都编码了一种情感状态。

### 30.1 十种情绪构图公式

| 情绪 | 构图公式 | 为什么 | 提示词 | 西幻场景 |
|------|---------|--------|--------|---------|
| 孤独 | 主体+大面积负空间+偏置 | 空旷=无人=孤独 | `lonely composition, subject off-center, vast negative space, emptiness surrounding, isolated` | 城墙上单薄的身影，天空占4/5 |
| 压迫 | 主体被环境包围+低天花板+窄框 | 空间收窄=呼吸受限 | `oppressive composition, environment closing in, low ceiling, narrow framing, claustrophobic` | 地牢走廊，天花板压低 |
| 权力 | 中心+低角度+对称+清晰前景 | 仰望=臣服+对称=秩序 | `power composition, centered, low angle, symmetrical, clear foreground, dominant` | 国王居中仰拍，两侧卫兵 |
| 崇拜 | 极低角度+垂直纵深+光源在上 | 仰望+光从上来=神圣 | `reverence composition, extreme low angle, vertical depth, light source above, looking up at divine` | 仰望穹顶的彩光 |
| 恐惧 | 模糊图底+偏角+遮挡+暗>亮 | 不确定性=恐惧 | `fear composition, ambiguous figure-ground, dutch angle, foreground obscuring, dark dominant` | 黑暗中看不清威胁 |
| 亲密 | 极近+浅景深+暖光+无遮挡 | 距离近+无障碍=亲密 | `intimate composition, extreme close-up, shallow DOF, warm light, no obstruction, close` | 两人额头相抵 |
| 欲望 | 偏轴+柔焦+暖光+部分遮挡 | 看不全是=欲念 | `desire composition, off-axis, soft focus, warm glow, partial obstruction, yearning` | 隔帘看到的身影 |
| 混乱 | 多焦点+越轴+碎片构图 | 无主焦点=迷失 | `chaos composition, multiple focal points, axis broken, fragmented framing, disoriented` | 战场混战 |

## 32. 导演分镜决策体系 (Director's Storyboard Decision System)

> 从情绪出发，一步步决定：机位、构图、灯光、调色——像导演一样思考

### 32.1 分镜三问法 (The Three Questions)

每个镜头设计前必须回答：
1. **观众此刻应该感受到什么？** → 锁定情绪
2. **画面中什么信息是必须传达的？** → 锁定景别+构图
3. **这个镜头与前后镜头的关系是什么？** → 锁定运动+剪辑

### 32.2 情绪→分镜速查决策树

```
情绪类型判定:
├─ 高能量情绪(愤怒/恐惧/兴奋/震惊)
│   ├─ 快速运动: 手持晃动 / 甩镜 / 快剪
│   ├─ 极端构图: 特写 / 荷兰角 / 框中框
│   └─ 强对比: 硬光 / 高饱和 / 撞色
├─ 低能量情绪(悲伤/孤独/沉思/绝望)
│   ├─ 缓慢运动: 缓推 / 缓拉 / 长镜头
│   ├─ 空旷构图: 大远景 / 留白 / 负空间
│   └─ 低对比: 柔光 / 降饱和 / 冷色调
├─ 不确定情绪(悬疑/好奇/不安/迷惘)
│   ├─ 暧昧运动: 跟拍 / 慢速环绕 / 局部揭示
│   ├─ 不完整构图: 半遮 / 前景遮挡 / 离轴
│   └─ 混合信号: 明暗交错 / 冷暖共存 / 虚实混合
└─ 超然情绪(敬畏/神圣/超越/宁静)
    ├─ 稳定运动: 静止 / 缓慢摇臂升起 / 稳定器漂浮
    ├─ 仪式构图: 对称 / 中心 / 框中框
    └─ 统一色调: 金色 / 单色调 / 神圣光
```

### 32.3 镜头序列情绪渐变设计 (Shot Sequence Emotion Gradient)

| 渐变类型 | 中文 | 镜头序列 | 情绪曲线 | 示例 |
|---------|------|---------|---------|------|
| Intensification | 递强 | 远→中→近→特写 | 平静→紧张 | 骑士接近恶龙 |
| Dissolution | 溶解 | 特写→近→中→远 | 紧张→释放 | 战后脱甲 |
| Oscillation | 振荡 | 近↔远↔近↔远 | 纠结→抉择 | 说还是不说 |
| Spiral | 螺旋 | 环绕+逐步靠近 | 困惑→清醒 | 揭开真相 |
| Still→Break | 静→破 | 长静止→突然运动 | 压抑→爆发 | 暴风雨前的沉默 |
| Break→Still | 破→静 | 混乱→突然静止 | 爆发→余震 | 战斗结束的寂静 |
