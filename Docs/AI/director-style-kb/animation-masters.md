## 1. Makoto Shinkai (新海诚) — 光的极致(Your Name / Weathering with You / Suzume)

### 1.1 签名美学

| 维度 | 特征 | 英文提示词 |
|------|------|-----------|
| 运镜 | 航拍+极慢推入+时间lapse云+平行交叉 | aerial, extremely slow push-in, time-lapse clouds, parallel cross-cut, Shinkai-style |
| 构图 | 天空占60%+云层细节+地平线+人物小=天空即主角 | sky 60%, cloud detail, horizon, tiny figures, sky as protagonist, Shinkai-grade |
| 调色 | 极饱和蓝+橙紫黄昏+绿+光线过曝=光即情感 | extreme saturation blue, orange-purple twilight, green, light overexposure, light as emotion, Shinkai-palette |
| 光线 | 黄金时段+逆光+光斑+镜头光晕+体积光=光即奇迹 | golden hour, backlight, lens flare, volumetric light, light as miracle, Shinkai-lighting |
| 空间 | 天空+云+高空俯瞰+城市+乡村=距离即思念 | sky, clouds, high aerial, city, countryside, distance as longing, Shinkai-space |
| 叙事 | 距离=思念+时间=失去+奇迹=重逢+天气=情感 | distance as longing, time as loss, miracle as reunion, weather as emotion, Shinkai-narrative |

### 1.2 核心作品拉片

**Your Name (2016)**: 黄昏逢魔时刻(蓝+橙)=奇迹即短暂+彗星=毁灭即美丽+绳=连接即命运
AI适配: `twilight blue+orange, miracle as fleeting, comet as beautiful destruction, thread as connection, Shinkai-YourName`

**Weathering with You (2019)**: 雨+晴=控制即代价+天空=自由+少女=天气
AI适配: `rain+sunshine, control as cost, sky as freedom, girl as weather, Shinkai-Weathering`

**Suzume (2022)**: 废墟+门=过去即伤痕+关门=治愈+地震=创伤
AI适配: `ruins, door as past wound, closing door as healing, earthquake as trauma, Shinkai-Suzume`

### 1.3 AI短剧适配(中世纪西幻)

| 西幻场景 | Shinkai适配 | 提示词公式 |
|----------|-----------|-----------|
| 魔法天空/异象 | 天空60%+极饱和蓝+黄昏+彗星 | `sky dominant, extreme saturation blue, twilight, comet, Shinkai-grade, magical sky` |
| 远距离思念 | 平行交叉+距离+云+光 | `parallel cross-cut, distance, clouds, volumetric light, Shinkai-longing` |
| 魔法连接(绳/线) | 细线+光+黄昏+蓝橙 | `thread, light, twilight, blue+orange, connection as fate, Shinkai-bond` |
| 废墟关门(治愈) | 废墟+门+光+治愈 | `ruins, door, light, healing, Shinkai-Suzume, closure` |

## 2. Isao Takahata (高畑勋) — 日常的史诗(Grave of the Fireflies / Only Yesterday / The Tale of Princess Kaguya)

| 维度 | 特征 | 英文提示词 |

| 运镜 | 锁定+极慢+日常节奏+不加速+尊重时间 | locked, extremely slow, daily rhythm, no acceleration, respect time, Takahata-style |
| 构图 | 日常空间+食物+自然+手工质感=生活即构图 | everyday space, food, nature, handcrafted texture, life as composition, Takahata-grade |
| 调色 | 水彩+墨+自然色+去饱和暖=时间即褪色 | watercolor, ink, natural, desaturated warm, time as fading, Takahata-palette |

## 11. 动画→AI短剧适配原则

| 原则 | 解释 | 提示词技巧 |
|------|------|-----------|
| 停顿即叙事 | 动画可以静止=电影不行 | pause 3-5 seconds, still frame, breathing room, Miyazaki-style hold |
| 变形即魔法 | 动画变形=AI魔法效果 | morphing transformation, shape shift, magic as animation, reality bending |
| 色彩即情绪 | 动画色更自由=AI也可 | expressive color, not realistic, emotional palette, animation color freedom |
| 线条即风格 | 线条风格=AI风格化 | line art style, illustration feel, graphic, not photoreal, stylized |
| 层次即深度 | 多层背景=AI深度 | multi-layer background, parallax depth, foreground-midground-background, animation depth |
