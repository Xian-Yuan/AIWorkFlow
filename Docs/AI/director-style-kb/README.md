## 使用流程

1. **确定情绪**: 这段场景要让观众感受到什么？
2. **查路由表1**: 按情绪找到推荐导演+风格组合
3. **打开KB文件**: 找到对应导演的详细拉片分析和AI提示词
4. **查游戏路由(可选)**: 中世纪西幻场景可查路由表5获取游戏美学参考
5. **查速查手册**: 交叉引用DP灯光(13节)、构图(14节)、竖屏(15节)
6. **组装提示词**: 用6模块公式(Subject+Physical+Lighting+Composition+Camera+Style)组装
7. **适配竖屏**: 检查15节竖屏规则，确保9:16安全区
8. **物理真实感**: 逐项检查16节8层清单
