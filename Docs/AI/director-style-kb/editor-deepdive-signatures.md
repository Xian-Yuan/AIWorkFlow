## 1. The Cut as Emotion: 12 Editor Signatures

### 1.1 Walter Murch - Emotion-Driven Cut

| Dimension | Feature | English Prompt | Emotion Core | West-Fantasy |
|-----------|---------|---------------|-------------|-------------|
| Philosophy | Cut on emotion first, then image, then rhythm, then eye-trace, then 2D plane, then 3D space | Murch-six-rule, emotion>image>rhythm>eye>2D>3D | Emotion is king | All scenes |
| Rhythm | Breathing rhythm, sparse cuts, long holds, silence as cut | breathing rhythm, sparse cuts, long hold, silence | Patience | Ritual / Waiting / Solitude |
| Sound | Sound drives cut, audio bridge, J-cut precedes image | sound-driven cut, audio bridge, J-cut | Sound leads image | Magic / Ritual / Horror |
| Duration | Each shot held until emotion exhausted, never cut before | hold until emotion exhausted, never premature cut | Respect feeling | Death / Sacrifice / Revelation |
| Transition | Dissolve for time passage, hard cut for emotion shift | dissolve=time, hard=emotion | Transition = time vs emotion | Memory / Time jump |
| Signature | Rule of Six, 3-second minimum, trust audience intelligence | Murch-grade, rule of six, trust audience, 9:16 | Intelligence | All narrative |

**Murch Cut Decision Tree**:
```
1. Does this cut support the EMOTION? → If yes, cut here
2. Does it advance the STORY? → If yes, consider
3. Does it create RHYTHM? → If yes, use
4. Does it follow EYE TRACE? → If yes, refine
5. Does it respect 2D COMPOSITION? → If yes, adjust
6. Does it maintain 3D SPACE? → If yes, finalize
```
