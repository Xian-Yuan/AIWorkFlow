> 关联: `medieval-fantasy-pattern-library.md`(视觉范式) / `costume-armor-design.md`(铠甲设计) / `medieval-fantasy-quickref.md`(速查)

## 使用方法

1. 确定角色类型 → 查下表
2. 复制"完整AI提示词" → 粘贴到AI视频工具
3. 结合场景意图 → 叠加导演+DP风格

## 1. 黑骑士(Dark Knight) — 忠诚/悲壮/不可折

| 维度 | 视觉配方 | 英文提示词 |
|------|---------|-----------|
| 体型 | 高大/宽肩/沉重 | tall, broad shoulders, heavy build, imposing silhouette |

| 披风 | 深色撕裂+风动 | dark torn cloak, wind catching, battle-worn fabric |
| 面部 | 疤痕+凝视+颌紧咬 | scarred face, thousand-yard stare, jaw clenched, weathered |
| 光线 | Deakins窗光+负填充 | Deakins single key window light, negative fill, no top light |
| 构图 | Kubrick中心对称+低角度 | Kubrick centered symmetry, low angle, imposing presence |
| 调色 | 冷蓝+碎黑+Vision3 500T | cold blue crushed blacks, Kodak Vision3 500T, desaturated |
| 景别 | MS→CU渐进 | medium to close-up progressive |

**完整提示词**:
```
A tall broad-shouldered knight in blackened plate armor with worn blood-rust patina,
dark torn cloak catching wind, scarred face with thousand-yard stare jaw clenched,

cold blue crushed blacks Vision3 500T, 9:16 vertical cinematic dark fantasy
Negative: bright, cartoon, anime, shiny, new armor, clean
```
