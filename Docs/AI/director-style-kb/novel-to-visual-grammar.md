## 6. Adaptation-Specific Techniques (10 Rules)

> When adapting novels/scripts to AI short video, these rules prevent common failures

| # | Rule | Problem | Solution | Example |
|---|------|---------|----------|--------|
| 1 | Show the world, not the narrator | AI cannot narrate | Replace narration with visual world-building | Instead of voice-over, show architecture that tells the story |
| 2 | Internal monologue becomes ECU | Thoughts are invisible | ECU on face shows internal state | Doubt = eyes darting + lip micro-tremble, locked ECU 85mm |
| 3 | Flashback = dissolve + warm | Past is warmer than present | Color-code temporal shifts | Warm amber dissolve = flashback, cold blue locked = present |
| 4 | Description becomes composition | Prose describes = camera composes | Translate adjectives to framing | Vast = 14mm, intimate = 85mm, oppressive = tight + dark |
| 5 | Off-page = off-screen | What reader imagines = what viewer does not see | Leave horror off-screen | Dragon suggestion > dragon reveal for first 3 appearances |
| 6 | Time skip = match cut | Years passing needs visual bridge | Match cut on same element across time | Same window, different season; same sword, different hand |
| 7 | Subtext = color conflict | Hidden meaning = color contradiction | Surface says one thing, color says another | Smiling face + cold blue light = hidden grief |
| 8 | Pacing = shot duration | Paragraph length = shot length | Long descriptive = long hold, action = fast cut | Battle: 1-2s cuts; landscape: 4-6s holds |
| 9 | Foreshadowing = visual echo | Plant seeds visually | Repeat a motif with variation | Broken sword in Act 1 = reforged in Act 3 (same composition) |
| 10 | Dramatic irony = split frame | Audience knows more than character | Show what character cannot see | Character looks forward, mirror/shadow shows threat behind |

## 8. Text-to-Prompt Workflow (5 Steps)

> Turn any written scene into AI video prompts in 5 steps

### Step 1: Identify Emotion Core
Read the scene. What is the PRIMARY emotion? Look it up in Section 4.

### Step 2: Find Visual Formula
Map the emotion to its visual formula (camera + light + color + composition).

### Step 3: Match Director Voice
Which director-narrator (Section 7) matches the tone? Apply their camera voice.

### Step 4: Translate Key Phrases
Use Section 1 rules to translate each key descriptive phrase into visual language.

### Step 5: Assemble Prompt
Combine: Emotion formula + Director voice + Key phrase translations + 9:16

**Example Workflow**:

| Step | Input | Output |
|------|-------|--------|
| 1. Emotion | The knight realized he was doomed | Dread |
| 2. Visual | Dread = slow push + locked + diminishing light + desat cold | slow push locked, dim, desat cold |
| 3. Director | Eggers archaeologist | candle-only, historical, face from dark |
| 4. Translate | Doomed = corridor + no escape (Rule 20) | corridor, no escape, inevitable |
| 5. Assemble | All combined | dread, slow push locked, candle-only diminishing, desat cold corridor no escape, Eggers historical, 9:16 |
