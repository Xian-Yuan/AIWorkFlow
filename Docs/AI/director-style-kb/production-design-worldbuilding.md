## 4. 世界一致性检查清单

### 4.1 AI短剧世界一致性8项

| 检查项 | 规则 | 违反示例 |
|--------|------|---------|
| 建筑风格 | 同一文明建筑风格一致 | 罗曼式城堡出现哥特窗 |
| 材质逻辑 | 建筑材质符合地理/技术 | 沙漠城市大量木建筑 |
| 技术水平 | 技术/魔法水平一致 | 中世纪场景出现玻璃窗 |
| 色彩体系 | 同一区域/文明色彩一致 | 北方要塞出现热带色 |
| 光源逻辑 | 光源符合技术水平 | 蜡烛场景出现LED效果 |
| 服装一致 | 同一文化服装风格统一 | 同一城堡两种不同风格铠甲 |
| 道具真实 | 道具符合时代/文化 | 中世纪桌上出现书籍(应卷轴) |
| 天气逻辑 | 天气符合地理/季节 | 北方冬天出现绿树 |

### 4.2 AI提示词中确保一致性的关键词

`
consistent architecture: [风格], consistent materials: [材质], period-accurate lighting: [光源],
same cultural style throughout, no anachronisms, [文明] aesthetic only
`

## 10. 世界一致性检查清单(深化版)

### 10.1 视觉一致性

| 检查项 | 问题 | 不一致信号 | 修复 |
|--------|------|-----------|------|
| 建筑风格 | 所有建筑是否同一时代风格? | 罗曼式城堡+哥特式窗 | consistent Romanesque architecture throughout, no anachronistic Gothic elements |
| 材质逻辑 | 材料是否符合时代? | 钢铁在青铜时代 | period-accurate materials, iron not steel, stone not concrete, wood+iron+cloth |
| 光源逻辑 | 所有光源是否合理? | 无火源的亮光 | ll light sources motivated, candle/torch/fireplace/sunlight only, no unmotivated light |
| 服装统一 | 同一文化服装是否统一? | 不同风格混搭 | consistent costume culture, same kingdom same silhouette, fabric+color coded by class |
| 道具时代 | 道具是否同一时期? | 现代工具在古代 | period-accurate props, no modern elements, hand-forged tools, no machined parts |

### 10.2 叙事一致性

| 检查项 | 问题 | 不一致信号 | 修复 |
|--------|------|-----------|------|
| 魔法规则 | 魔法是否遵循同一规则? | 同一咒语不同效果 | consistent magic system, same spell same effect, magic has cost and limitation |
| 阶级结构 | 阶级是否前后一致? | 角色突然改变阶级 | consistent class structure, birth determines station, clothing reflects rank |
| 宗教体系 | 信仰是否统一? | 矛盾的神祇描述 | consistent religious system, same gods same rituals, faith has rules |
| 经济逻辑 | 交易是否合理? | 平民拥有贵族物品 | consistent economy, wealth reflects class, trade follows geography |
