# Spec: contract-verify status Command

## GIVEN
- A task with contract.yaml generated by `contract-verify init`
- OR a task without contract.yaml

## WHEN
- User runs `contract-verify.ps1 <task> status`

## THEN
- For tasks WITH contract.yaml:
  - Output a summary table with columns: Phase, Total, Pass, Fail, Blocking
  - Show overall status: ALL PASS / HAS FAILURES / BLOCKED
  - Exit code: 0 if all pass, 1 if any blocking failure
- For tasks WITHOUT contract.yaml:
  - Output: "No contract.yaml found. Run 'contract-verify init' first."
  - Exit code: 1

## Constraints
- Must NOT modify any files (read-only command)
- Must NOT run verification checks (just parse contract.yaml + existing report data)
- Must reuse existing YAML parsing infrastructure from init/verify commands
- Output format: plain text table, no markdown
